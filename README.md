# Cazafantasmas: Noche de Halloween

## Contexto
Este proyecto es un videojuego 2D de temática de Halloween. El jugador intenta atrapar fantasmas haciendo clic sobre ellos mientras se mueven por un escenario nocturno.

## Objetivo
Aplicar los fundamentos de graficación por computadora mediante Canvas 2D, animación de objetos, detección de colisiones, interacción con el mouse y publicación de un sitio web.

## Justificación
El juego permite practicar conceptos de movimiento, coordenadas, velocidad, rebote y detección de colisiones de una forma visual e interactiva. Además, integra HTML, CSS, JavaScript, Bootstrap y control de versiones con Git y GitHub.

## Operación
1. Abre `index.html` en un navegador moderno.
2. Haz clic sobre los fantasmas para atraparlos y aumentar el contador.
3. Los fantasmas vuelven a aparecer en una nueva posición, por lo que se mantienen 25 objetos.
4. Los fantasmas se desplazan en diferentes trayectorias y rebotan al tocar los límites o chocar con otros.
5. Usa el botón **Activar música** para activar el sonido ambiental. El audio comienza solo después de hacer clic, por las restricciones habituales de los navegadores.
6. Pulsa **Reiniciar** para comenzar otra vez desde cero.

## Tecnologías

- CSS

## Conclusiones
Con este proyecto se practica la creación de un escenario gráfico en dos dimensiones y el movimiento de objetos mediante JavaScript. La detección de colisiones permite cambiar la trayectoria de los fantasmas y mostrar un efecto visual de impacto. La interacción con el mouse agrega una meta al juego y el contador permite observar el resultado de las acciones del jugador. Git y GitHub ayudan a registrar cambios y publicar la aplicación para que pueda ejecutarse en línea.
